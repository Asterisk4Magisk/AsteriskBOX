# bpfmatcher

`bpfmatcher` loads and pins eBPF socket-filter programs used by iptables `xt_bpf` rules. It supports UID selection, optional direct-CIDR bypass, IPv4/IPv6 OUTPUT matching, and PREROUTING matching.

The source root contains one production translation unit, `bpf-matcher.c`. A parent Android project compiles it as a root PIE executable, commonly packaged as `libbpf-matcher.so`.

## Command line

```text
bpf-matcher --probe [--json] --bpf-dir DIR [--ipv6 0|1]
bpf-matcher --start --policy FILE
bpf-matcher --stop --policy FILE
```

| Option | Description |
| --- | --- |
| `--probe` | Probe required map, program-load, direct-packet-access, and object-pin capabilities. |
| `--json` | Compatibility flag. Probe output is JSON whether this flag is present or not. |
| `--bpf-dir DIR` | Required absolute pinned-filesystem directory for temporary probe objects. No default is used. |
| `--ipv6 0\|1` | Include IPv6 capability checks when set to `1`; the default is `0`. |
| `--start` | Load programs described by the policy and pin them at its four explicit paths. |
| `--stop` | Unlink the four pinned programs described by the policy. |
| `--policy FILE` | Required absolute JSON policy path for both `--start` and `--stop`. |

Exit status is `0` on success, `1` when a runtime probe capability is unsupported, and `2` for invalid arguments, invalid policy, or start-time BPF setup failure.

## Policy

```json
{
  "mode": 2,
  "bypassDirectCidrs": true,
  "enableIpv6": true,
  "directCidrPathV4": "/data/local/tmp/example/direct-v4.txt",
  "directCidrPathV6": "/data/local/tmp/example/direct-v6.txt",
  "xtOutputV4ProgramPath": "/sys/fs/bpf/example/xt_output_v4",
  "xtOutputV6ProgramPath": "/sys/fs/bpf/example/xt_output_v6",
  "xtPreroutingV4ProgramPath": "/sys/fs/bpf/example/xt_prerouting_v4",
  "xtPreroutingV6ProgramPath": "/sys/fs/bpf/example/xt_prerouting_v6",
  "uids": [10001, 10002]
}
```

| Field | Required | Description |
| --- | --- | --- |
| `mode` | no | `0` blacklist, `1` whitelist, or `2` global; default `2`. |
| `bypassDirectCidrs` | no | Load direct-CIDR maps and bypass matching entries; default `false`. |
| `enableIpv6` | no | Load and pin IPv6 programs; default `true`. |
| `directCidrPathV4` | conditional | Required when direct-CIDR bypass is enabled. One CIDR per line; `#` begins a comment. |
| `directCidrPathV6` | conditional | Required when direct-CIDR bypass and IPv6 are enabled. |
| `xtOutputV4ProgramPath` | yes | Absolute path for the IPv4 OUTPUT program. |
| `xtOutputV6ProgramPath` | yes | Absolute path for the IPv6 OUTPUT program, required even when IPv6 is disabled so the same policy can safely stop resources. |
| `xtPreroutingV4ProgramPath` | yes | Absolute path for the IPv4 PREROUTING program. |
| `xtPreroutingV6ProgramPath` | yes | Absolute path for the IPv6 PREROUTING program, always required. |
| `uids` | no | UID set used by blacklist/whitelist modes; maximum 8192 values. |

All configured paths must be shorter than 512 bytes. Probe directory validation also reserves enough space for the longest derived probe filename. Probe cleanup unlinks only its derived temporary objects and never removes the caller-supplied directory.

## Platform requirements and safety

The executable must run as root on Android/Linux with the `bpf` syscall, required map and socket-filter program types, a mounted BPF filesystem, and permission to pin objects. Start and stop policies should be generated by trusted code: `--stop` unlinks exactly the four paths in the policy.

## Parent-project integration

Mount the repository root directly at `bpfmatcher/src/main/native`. Keep Android ABI selection, NDK flags, packaging, and task wiring in the parent project. The `tests` subdirectory is not a production source input.
